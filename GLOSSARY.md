# HDB resale map

Language for comparing HDB resale and rental values within a selected area.

## Language

**Heatmap**:
The coloured map points that show the active metric, such as resale price or gross rental yield. In this project, heatmap does not mean a continuous density surface.

**Selected area**:
The circle or rectangle chosen by the user for spatial comparisons.

**Map metric**:
The value represented by each heatmap point's colour, such as resale price, monthly rent or gross rental yield.

**Selection tool**:
The circle or box drawing control used to choose a selected area.
